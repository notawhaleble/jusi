# Готовые плагины

Для Jusi готовы к использованию Shell, PostgreSQL, ClickHouse и GigaCode.
Устанавливайте выбранный пакет в Python-окружение, в котором работают
сервис Jusi и ядро целевого узла. Для удалённого узла или Docker установка
выполняется в этом окружении.

После установки или обновления выполните `:JusiRestart` в работающем
блокноте либо остановите и снова запустите его. Плагины обнаруживаются
при запуске среды выполнения.

## Shell

```sh
pip install jusi-shell
```

`jusi-shell` открывает интерактивную оболочку через `%%shell`.
Повторные запросы отправляются в ту же работающую оболочку;
поддерживается автодополнение путей. Например, `%%shell bash` выбирает Bash,
а `%%shell --cwd /path/to/project` задаёт рабочий каталог.
Для открытия оболочки из другого буфера можно использовать
[команду JShell](useful-commands.md).

## PostgreSQL

```sh
pip install jusi-postgres
```

`jusi-postgres` выполняет запросы к PostgreSQL через `%%sql <alias>`
и показывает результаты в VisiData. Зависимость `jusi-sql` устанавливается
автоматически. Настройте SQL-подключение с провайдером `postgres`
в `~/.jusi/jusi.toml` на целевом узле. Повторные запросы используют
то же подключение и транзакцию; поддерживается прерывание запросов.

## GigaCode

```sh
pip install jusi-gigacode
```

`jusi-gigacode` подключает агента GigaCode через Agent Client Protocol
и магическую команду `%%acp <alias>`. Зависимость `jusi-acp` устанавливается
автоматически. Требуется Python 3.10+ и отдельно установленная команда
`gigacode`, доступная в PATH целевого узла. В `~/.jusi/jusi.toml` настройте
ACP-псевдоним с провайдером `gigacode` и каталогом проекта.
Плагин поддерживает повторные запросы в одном сеансе, запросы разрешений,
отмену и уведомления о необходимости внимания.
