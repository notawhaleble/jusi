# Веб-представление

При наличии команды `JusiWebBuffer`, например в `jusi-neovim`, расширенный
вывод Jupyter автоматически открывается в веб-буферах без переноса фокуса
из блокнота. Если у ячейки уже есть видимое окно вывода, веб-буфер открывается
в нём. Предыдущий текст остаётся в сохранённом терминальном буфере.
Порядок предпочтения MIME: `text/html`, `image/svg+xml`, `image/png`,
`image/jpeg`, `image/gif`, `application/javascript`, `text/javascript`.
Обычный Neovim показывает вариант `text/plain`.

Для matplotlib включите встроенный вывод в блокноте:

```python
%matplotlib inline
import matplotlib.pyplot as plt
plt.plot([1, 2, 3], [1, 4, 2])
plt.show()
```

Пример без дополнительных зависимостей, кроме IPython:

```python
from IPython.display import HTML, display
display(HTML('<h1>Привет из Jusi</h1>'))
```

Магическая команда IPython `%%javascript` выполняет JavaScript браузера
в отдельном веб-документе:

```javascript
%%javascript
const heading = document.createElement('h1');
heading.textContent = 'Привет из JavaScript';
element.appendChild(heading);
```

`element` — стандартный элемент DOM, предоставленный как контейнер вывода.
Используйте DOM, canvas и API браузера; jQuery, виджеты Jupyter, глобальные
переменные блокнота и доступ к переменным Python не предоставляются.
Ошибки JavaScript показываются на странице. Каждый вывод получает отдельный
документ; переменные не переносятся между ячейками. Выполнение ядра не ждёт
браузерный скрипт; ошибки скрипта не меняют результат выполнения ядра.

Расширенный вывод принадлежит ячейке. Обычное закрытие окна скрывает его;
`JusiToggleFocus` возвращает к последнему расширенному представлению,
а `JusiClose` удаляет вывод ячейки. Новое выполнение и очистка среды удаляют
буферы и временные файлы. Каждый вывод — снимок; обновления display-id
и clear-output пока не реализованы. Размер одного закодированного пакета
ограничен 16 МиБ; для больших пакетов используется текстовый вариант.

Терминальное приложение, чей клиент объявляет `editor_actions`, может открыть
ссылку:

```python
from jusi.editor_client import open_url
open_url('https://example.com/report')
```

Вызов ждёт подтверждения доставки; при необходимости вызывайте его вне потока
интерфейса приложения. Отсутствие команды веб-буфера приводит к
`EditorDeliveryError`. Новый веб-буфер сохраняется после закрытия исходного
клиента, как экспортированный текстовый снимок. Для результата рабочего
процесса `editor_action` возвращайте `jusi.plugin_api.open_url(url)`.

URL должен быть абсолютным HTTP(S)-адресом и доступным с узла редактора.
Сервер на `localhost` целевого узла не становится автоматически доступным
удалённому редактору. Неявного туннеля или обратного прокси нет. Эти функции
предоставляют общую навигацию плагинов; долговременный клиент только с вебом
требует отдельного будущего контракта поверхности.
См. [ADR 0052](docs/1.0/adr/0052-web-buffer-output-and-url-actions.md).
