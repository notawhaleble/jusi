# Проверки надёжности жизненного цикла

`tests/e2e/test_process_lifecycle.py` запускает изолированные редакторы
без интерфейса, сервисы, управляемые ядра и клиенты фикстур. Он фиксирует
точные идентификаторы процессов и очищает только эти ресурсы.
Все ожидания теста ограничены. Запуск:

```sh
.venv/bin/python -m pytest -q tests/e2e/test_process_lifecycle.py
```

Каждый случай проверяется в простое, при долгом выполнении, на `input()`,
с терминальным клиентом, во время ожидающего повторного запроса плагина
и при игнорировании SIGINT кодом ядра. У долгой работы намеренно нет
срока завершения приложения.

| Случай | Обязательное наблюдение |
| --- | --- |
| Neovim `:qa!`, принадлежащее редактору окружение | Сервис, ядро, рабочие процессы фикстур, терминал и локальные процессы транспорта завершаются. |
| Neovim SIGKILL, принадлежащее редактору окружение | EOF канала владельца вызывает ту же очистку без обработчиков выхода редактора. |
| Сервис SIGTERM | Обычная ограниченная очистка; фронтенд отключается. |
| Сервис SIGKILL | Управляемое ядро и потомки фикстур удаляются после потери владельца; фронтенд отключается. Последнее авторитетное событие не предполагается. |
| Ядро SIGKILL | Сервис сохраняется; фронтенд получает типизированную ошибку завершения ядра и `off`; клиенты, поверхности и активная работа удаляются. Новый идентификатор ядра успешно выполняет код. |
| Neovim `:qa!` или SIGKILL, внешнее окружение | Локальные инструменты транспорта завершаются. Целевой сервис, ядро, среда и активная работа сохраняют идентификаторы. Явная остановка через API успешна. |
| Туннель loopback обрывает соединения | Фронтенд отмечает транспорт отключённым, сохраняя ядро `on` как последнее известное. Работа может завершиться; переподключение восстанавливает достоверные сведения и один раз воспроизводит завершение. |
| Туннель loopback молча отбрасывает байты | Обнаружение неактивности SSE даёт то же отключение и восстановление без тайм-аута кода или ввода. |

Тесты внешнего окружения используют отдельно запущенный локальный сервис
без канала владельца. Тесты потери используют временный TCP-ретранслятор
перед этим сервисом. Они проверяют семантику удалённого транспорта
без другой машины или SSH.

## Последующая ручная проверка удалённого окружения

Запустите удалённое окружение и долгую ячейку, затем нарушьте туннель
или сетевой путь. Редактирование блокнота должно оставаться отзывчивым.
Строка состояния должна показывать последнее известное состояние ядра,
а не объявлять его выключенным. Восстановите путь и используйте `JusiConnect`
для переподключения существующего сеанса. Нужно согласовать ту же целевую
среду и показать завершённый вывод без повторного выполнения ячейки.
Отдельно проверьте восстановление интерактивного терминала.

Проверка на удалённой машине отложена. Автоматические тесты не подтверждают
восстановление сеанса в новом редакторе, долговременные события при замене
сервиса, очистку произвольных отсоединённых дочерних процессов или поведение
при приостановке хоста и потере питания.
