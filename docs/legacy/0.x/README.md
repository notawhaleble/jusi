# Jusi 0.x Historical Documentation

Everything in this directory describes or discusses the former two-repository Jusi backend architecture. It is retained as evidence and is not normative for Jusi 1.0.

The documents intentionally retain concepts that the rewrite rejects, including durable reconnectable sessions, `failed` session state, stdio protocol behavior, inspection polling, and process-oriented terminal attachment.

For the rewrite, start with `../../1.0/intent.md`.
