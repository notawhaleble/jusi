# Демонстрация для быстрого старта

Перед редактированием скопируйте `quickstart.vipynb` в рабочий каталог.
Установите Jusi с дополнительной зависимостью `vd` и фронтенд Neovim
той же версии, как описано в [руководстве по установке](../docs/1.0/installation.md).

Для короткой записи можно использовать такую последовательность:

1. Откройте копию и выполните `:JusiStart local`. Выполните первую ячейку,
   чтобы показать `42`.
2. Нажмите пробел для перехода в режим ячеек. На первой ячейке нажмите `S`,
   чтобы закрепить вывод; появится отметка `~`. Перейдите ко второй ячейке
   клавишей `j` и отправьте её нажатием Enter. Покажите `45` и сохранённый
   вывод первой ячейки.
3. Перейдите к `%%vd` и отправьте ячейку. Нажмите Ctrl-\ дважды для перехода
   в её терминал. Выберите имя, нажмите `zY`, затем Ctrl-O, чтобы открыть
   значение в отдельном окне. Закройте экспортированное окно командой `:close`,
   при необходимости предварительно вернувшись в обычный режим.
4. Верните фокус в блокнот. Отправьте ячейку с запросом ввода, замените её тело
   на `Ада` и отправьте ещё раз. Покажите буквальный ответ и `Привет, Ада!`.
5. Выполните `:JusiStop` и покажите индикатор `off` и закрытые окна вывода.

Дополнительный кадр с автодополнением: создайте ячейку клавишей `B`, введите
`from time imp` и нажмите Tab. Выберите и подтвердите результат стандартными
клавишами автодополнения.

Используйте только вымышленные данные. Выберите читаемый шрифт терминала
и держите блокнот и вывод на экране. Это сценарий записи, а не автоматическая
демонстрация или готовое видео. В этом сценарии ответ на запрос ядра заменяет
активное тело ячейки, поэтому для следующего дубля возьмите свежую копию.
